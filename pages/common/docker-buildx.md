# docker buildx

> Docker CLI plugin for extended build capabilities with BuildKit.
> Some subcommands such as `build`, `create`, `inspect`, `ls`, `prune`, `rm`, `stop`, `use`, `du`, and `version` have their own usage documentation.
> See also: `docker build`.
> More information: <https://docs.docker.com/reference/cli/docker/buildx/>.

- View documentation for building an image:

`tldr docker buildx build`

- View documentation for creating a builder instance:

`tldr docker buildx create`

- View documentation for listing builder instances:

`tldr docker buildx ls`

- View documentation for inspecting a builder instance:

`tldr docker buildx inspect`

- View documentation for selecting the current builder instance:

`tldr docker buildx use`

- View documentation for removing a builder instance:

`tldr docker buildx rm`

- View documentation for removing unused build cache:

`tldr docker buildx prune`

- View documentation for displaying the version:

`tldr docker buildx version`
