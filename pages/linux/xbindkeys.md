# xbindkeys

> Grab key and mouse button events in X and start the associated shell commands.
> More information: <https://mankier.com/1/xbindkeys>.

- Grab key and mouse button events using `$HOME/.xbindkeysrc`:

`xbindkeys`

- Use an alternative configuration file:

`xbindkeys --file={{path/to/.xbindkeysrc}}`

- Run on a specific X display:

`xbindkeys --display={{:0}}`

- Do not start as a daemon:

`xbindkeys --nodaemon`

- Print a default configuration file:

`xbindkeys --defaults`

- Print more information while running:

`xbindkeys --verbose`

- Identify the key that is pressed, to help write the configuration:

`xbindkeys --key`

- Display help:

`xbindkeys --help`
